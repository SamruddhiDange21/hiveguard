📖 CONDITION INTERPRETATION LAYER

HEALTHY

Stable temperature (33.5–35.5°C), stable humidity (50–65%), gradual weight progression.

COLONY STRESS

Temperature deviation, persistent elevated humidity, progressive weight decline.

SWARMING RISK

Rapid biomass loss over short periods, ventilation and thermal pattern changes.

VARROA RISK

Possible Varroa-related risk pattern: persistent microclimate depression and weight decline. (Not confirmed infection).

SENSOR ANOMALY

Abrupt impossible value in single sensor (e.g. temp >41°C) with others stable.

ABOUT HIVEGUARD

Precision Apiculture IoT & Anomaly Prediction System

HIVEGUARD is an autonomous apiary monitoring system designed to protect Apis cerana indica colonies through continuous sensor telemetry and machine learning.

Target Anomaly Categories:

  • Healthy: Optimal autonomous brood nest thermoregulation (~34.4°C).
  • Colony Stress: Synchronous thermal and humidity deviations with biomass decline.
  • Swarming Risk: Sudden biomass reduction signaling colony division.
  • Varroa Risk: Chronic microclimate depression requiring physical sticky-board washes.
  • Sensor Anomaly: Isolated hardware probe errors.

Technical Stack:

Backend: Flask (Python 3.10+), scikit-learn, XGBoost, pandas, NumPy.
Frontend: HTML5, CSS3, Vanilla JavaScript, Chart.js.
Communication: REST API JSON endpoints.
